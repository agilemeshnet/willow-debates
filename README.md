# DEBATES

Archive of Trivium-watchmaker debates run by the Willow team.

See [SHAPE.md](SHAPE.md) for the experimental design, phase rules, seat
configuration, and filing convention. SHAPE.md is the canonical plan;
this README is the front door.

## Browsing the archive

- [INDEX.md](INDEX.md) — human-readable index of debates
- `Debates/<date-time>-<slug>/` — one directory per debate
- `git log --all` — chronological view of every speech across every
  debate, each commit authored by the speaker

## Provenance

Repo seeded 2026-06-02. The principle behind the structure:
*"A repo has the same shape as a debate."*
